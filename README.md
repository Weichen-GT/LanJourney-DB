# LanJourney-DB

Database files for LanJourney (PostgreSQL).

| Path | Contents |
|---|---|
| `schema.sql` / `reset.sql` | Schema and reset script |
| `migrations/` | Hand-run SQL migrations (no runner; backend uses `ddl-auto=validate`) |
| `initial_vocab_final_data.sql`, `wordnet_full_data.sql`, `frequency_rank_10k.sql` | Seed data, generated by LanJourney-lib; loaded by the backend's `docker-compose.yml` |
| `updates/` | In-place data updates already applied to prod (the Claude quality pass; the 2026-10-01 re-do of 171 WordNet-sourced words) |
| `archive/` | Superseded SQL |
